## Описание проекта
Программа представляет собой Telegram-бота, разработанного для любителей книг. Бот помогает формировать привычку к чтению, предлагая ежедневные отрывки, рекомендации литературы и инструменты для отслеживания личного прогресса.

## Функциональные возможности
### Основной функционал
- 📖 **Ежедневные отрывки из книг:** регулярная рассылка интересных цитат (в разработке).
- 📚 **Рекомендации книг:** подборки литературы (/recommend).
- 📊 **Отслеживание прочитанного:** ведение статистики прочитанных страниц (/track, /stats).
- ⏰ **Напоминания о чтении:** настраиваемые уведомления для поддержания привычки.

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `python-telegram-bot`
